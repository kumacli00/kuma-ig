疲れてないのに疲れて見える人の共通点まず1本目

共有狙い クイズ・問いかけ 30代〜40代で「しっかり寝たのに周りから疲労感を心配される」人
冒頭で言う

「「今日疲れてる？」ってよく言われる方、実は寝不足のせいじゃないかもしれません。」

送る相手の一言

「疲れてないのに疲れてる？と聞かれがちな同僚や友人」に送ってあげてください

流れ
  1. 院長が「疲れてる？と聞かれる原因は寝不足ではなく目の下の段差影であること」を提示する
  2. 模型にペンライトを当て、上からの照明で目の下に黒い影が落ちる様子を実演する
  3. 皮膚の色ではなく立体的なふくらみが影を作っている仕組みを種明かしする
  4. マッサージで悪化させず、影の原因を見極める大切さを伝える
  5. 「周りにこの悩みを持っている方がいたらシェアして教えてあげてください」と結ぶ
演出

院長が診察室でペンライトを持ち、頭上照明を模して模型の目元に影を作る実験風の画角。影が出た瞬間に画面をアップにし、テロップで「原因は影」と強調。

キャプションの冒頭

「疲れてないのに疲れてる？」とよく聞かれるお友達はいませんか？ 実はそれ、寝不足ではなく目の下の構造による影が原因かもしれません。

根拠と、気をつける点
なぜ効くか

「人に送られた本の手本」にある『◯◯クマから治し始めた人、たぶん遠回りしています。（共有率0.28）』や『クマ治療で運命が変わる！？（共有率0.56）』を踏まえ、誰かの顔が浮かぶ「周囲から疲れて見えると言われる悩み」をフックにして共有を促すため。

気をつける点

「寝不足を解消すれば改善する」等の断定を避け、ふくらみによる影で疲れた印象に見えやすいメカニズムの説明に留める。

クマを隠そうとして逆に目立つNGメイク

共有狙い 禁止・警告 20代後半〜40代で、クマを隠すためにファンデやコンシーラーを厚塗りして崩れに悩む女性
冒頭で言う

「コンシーラーを重ねれば重ねるほど、夕方に目の下がシワシワになって老けて見えていませんか？」

送る相手の一言

「クマを隠そうと毎日メイクを頑張っている友達」に送ってあげてください

流れ
  1. 院長が手の甲に濃いコンシーラーを厚塗りし、皮膚を動かしてヨレる様子を実演する
  2. 色を消そうとするほど「段差」が強調されて小じわに入り込むメカニズムを解説する
  3. ふくらみによる影はメイクで埋めることが難しい理由を模型で説明する
  4. 厚塗りをやめて立体感を整える視点を持つことの重要性を提示する
  5. 「メイク直しで悩んでいるお友達に共有して教えてあげてください」と呼びかける
演出

院長の手元アップでコンシーラーのヨレを検証するビジュアル。ごとに手元アップと院長の解説バストアップを切り替え、テンポよく見せる。

キャプションの冒頭

毎朝コンシーラーでクマを必死に隠しているお友達に教えてあげてください。 実は厚塗りするほど夕方の小じわや影が目立ってしまうことがあります。

根拠と、気をつける点
なぜ効くか

「当たった本が1言目に実際に言っていた言葉」にある『頬の毛穴が汚すぎて辛いです〜（共有率0.11）』の共感型フックと、日常の失敗あるあるから「友達に教えてあげたい」と思わせる共有導線を組み合わせたため。

気をつける点

特定の化粧品ブランドを否定せず、立体的なふくらみに対してペースト状のメイクを重ねる物理的なヨレやすさの説明に徹する。

写真の他撮りで目の下が暗い人の理由

共有狙い 指示語で引っかける 20代〜30代女性で、集合写真や他撮り写真で目元の影が気になり始めた人
冒頭で言う

「友達と撮った写真を見て、「あれ、私だけ目の下が暗い？」ってギクッとしたことありませんか？」

送る相手の一言

「他撮り写真の写りを気にしているお友達」に送ってあげてください

流れ
  1. スマホカメラの画面を見せながら、自撮り（正面光）と他撮り（上からの自然光）での見え方の違いを実演する
  2. 正面から見ると目立たない段差が、角度によって濃い影として写り込む理由を解説する
  3. 自分で鏡を見る時と、人から見られる時・写真での見え方のギャップを検証する
  4. 自分の目元がどのタイプかチェックする方法を伝える
  5. 「写真写りを気にしているお友達に送ってあげてください」と結ぶ
演出

院長が実際にスマホを持ってカメラ画角を切り替える動きのある構図。照明の位置を変えて目元の影の出方をリアルタイムで再現する実演演出。

キャプションの冒頭

みんなで撮った写真を見て目の下の影を気にしているお友達はいませんか？ 自撮りでは気づきにくい「他撮りでの影の出方」について解説しました。

根拠と、気をつける点
なぜ効くか

「人に送られた本の手本」の『【目の下のたるみ】クマ治療した結果...（共有率0.37）』のように、ビジュアルでの共感性が高く「これ私たちのあるあるだよね」とDMで送り合えるテーマであるため。

気をつける点

特になし。写真の光の当たり方と目元の陰影の出方についての解説。

目元の相談前に自分で見るべき３つの確認

保存狙い 依頼形 クマ取りや目元治療を考え始めており、失敗したくない30代〜50代
冒頭で言う

「目元のカウンセリングに行く前に、ご自身の手鏡でこれだけは確認しておいてください。」

送る相手の一言

目元の治療を検討し始めたご自身のために保存しておいてください

流れ
  1. 院長が手鏡を持ち、患者目線でチェックすべき3つのポイントを実演する
  2. チェック1：上を向いた時にふくらみが引っ込むかどうか（脂肪の動き）
  3. チェック2：指で頬を軽く持ち上げた時に影が薄くなるか（皮膚のたるみ）
  4. チェック3：下まぶたを優しく引っ張った時に色が変わるか（血行・皮膚の色味）
  5. 「自分のタイプを知ってから相談に行くと納得度が変わります」とまとめる
  6. 「カウンセリング当日に見返せるよう保存しておいてください」とCTA
演出

院長自身が鏡を持ちながら顔の角度を変えたり指で触れる動作を実演。画面右側に「チェック①・②・③」のチェックリストテロップを固定表示し、保存して見返したくなるデザインにする。

キャプションの冒頭

目元のカウンセリングに行く前に、まずは自分でチェックしておきませんか？ 後から見返せるように「保存」して鏡の前で確認してみてください。

根拠と、気をつける点
なぜ効くか

「保存された本の手本」で高数値を記録した『カウンセリングで絶対に聞いたほうがいいこと3選（保存率0.66）』の「判断基準をあげる型」を直近実績から踏襲し、保存率を高める構成にしたため。

気をつける点

自己診断で断定させず「医師の診察時に状態を正しく伝えるためのセルフチェック」という位置づけを明記する。

目の下のコレただのクマと思ってない？

視聴時間狙い 指示語で引っかける 目の下のふくらみやポツポツが年々気になってきている全年代
冒頭で言う

「みなさん、目の下にできたこれ、単なる寝不足のクマだと思っていませんか？」

送る相手の一言

目の下にポツポツや独特のふくらみがある家族や友達に教えてあげてください

流れ
  1. 院長が目元の拡大イラストや模型を指差し、「クマに見えて実は違うもの」を提示する
  2. 「単なる脂肪のふくらみ」「皮膚のポツポツ（汗管腫など）」「たるみによる段差」の3つを比較する
  3. それぞれの見分け方を模型を使いながら順番に種明かししていく
  4. 自己流でマッサージやクリームを塗っても変化を感じにくい理由を解説する
  5. 正しく見極めて適切なアプローチを選ぶ大切さを伝えて最後まで維持させる
演出

冒頭で院長が指差す患部イラストにクエスチョンマークを配置。1つずつフリップや模型のパーツをめくりながら解説する「種明かし形式」で画面展開をテンポよく切り替える。

キャプションの冒頭

目の下のポツポツやふくらみ、諦めていませんか？ 実はクマ以外の原因が隠れているケースも少なくありません。

根拠と、気をつける点
なぜ効くか

「当たった本が1言目に実際に言っていた言葉」で最も平均視聴秒が長かった『その白いポツポツ〜（23.・再生3.1万）』および『目の下のこのブツブツ、正体知ってますか？（20.・再生12.5万）』の「指示語フック＋種明かし構成」を完全再現し、離脱を防ぐため。

気をつける点

疾患名や治療効果を断定せず、「状態によって見分け方や適したアプローチが異なる」という啓蒙に留める。
