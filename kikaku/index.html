親のクマ放置してない？まず1本目

共有狙い 意外・常識くずし 40代〜50代の親を持つ20代〜30代の子ども、または目元のたるみに悩む親世代
冒頭で言う

「一般の方が注意しなければならない、親世代のクマ放置の話です。」

送る相手の一言

ご両親や40代・50代の家族に教えてあげてください

流れ
  1. 手鏡を持ったスタッフの目元を毛利先生が診察しながら、たるみとクマの違いを指摘する
  2. 「ただの疲れ」と放置すると皮膚が伸びて視界や表情の印象に影響する理由を模型で実演する
  3. 年代別でアプローチが全く異なることをフリップで見せる
  4. まずは家庭でできる目元の影チェック法を先生が指で実演する
  5. 家族で一緒に確認できるよう促してまとめる
演出

毛利先生が白衣姿でスタッフの目元を優しく触診する手元アップから入る。途中で目元構造の立体模型を動かして脂肪の突出メカニズムを視覚化。

キャプションの冒頭

親にこれ教えてあげてください。目の下のクマ、年代で原因が違います。 「最近疲れてる？」と親に感じたら、まずはここをチェックしてみてください。

根拠と、気をつける点
なぜ効くか

「いま効く順」の『キャプション1行目に送る相手を書く』と、過去の高共有実績「◯◯クマから治し始めた人」「出川さんのクマの倒し方」など第三者の顔が浮かぶテーマが高シェアを出しているため。

気をつける点

「たるみが完全に消える」などの断定は避け、「スッキリした印象を目指せる」という表現に留める。

2

マッサージNGなクマ

共有狙い 禁止・警告 20代〜30代でセルフケア（マッサージ・美顔器）を熱心にやっている女性
冒頭で言う

「皆さん、目元ゴシゴシ揉んでる友達がいたら今すぐ止めてあげてください。」

送る相手の一言

毎日アイクリームを塗り込んでマッサージしている友達に送ってあげてください

流れ
  1. 先生がスキンケア中のマネキンを使い、よくあるNGマッサージを再現する
  2. 黒クマ（脂肪突出）と茶クマ（摩擦色素沈着）の違いをペンで図解する
  3. マッサージで刺激を与えると色素沈着が悪化しやすい理由を解説する
  4. 自分のクマタイプを判別する「あっかんべーチェック」を先生が手元で実演する
  5. 友達同士で確認し合えるよう呼びかける
演出

マネキンの顔に強めに指を当てるNG動作を大写しにして違和感を作る。その後、先生が鏡の前で自分の指を使って安全なセルフチェック法を実演。

キャプションの冒頭

クマを一生懸命揉んでる友達に送ってあげてください。 そのマッサージ、色素沈着を悪化させている可能性があります。

根拠と、気をつける点
なぜ効くか

「◯◯クマから治し始めた人、たぶん遠回りしています」（共有率0.28%）の実績と、「禁止・警告」のフックで第三者への注意喚起（シェア）を促す設計。

気をつける点

特定のスキンケア商品や美顔器を名指しで批判しないよう配慮する。

3

寝ても取れない目元

共有狙い 指示語で引っかける 20代〜40代の男女。「しっかり寝たのに目元が暗い」と言われる人
冒頭で言う

「これ、『寝不足だから』って言い訳してる同僚いませんか？」

送る相手の一言

いつも『寝不足でクマが取れない』と言っている同僚やパートナーへ

流れ
  1. 先生がカルテを見ながら「寝ても取れないクマの正体」について切り出す
  2. 青クマ（血行不良）と黒クマ（骨格・脂肪の影）の見分け方をライトを当てて実演する
  3. 上を向いた時に影が薄くなるなら寝不足ではなく脂肪の段差であると種明かしする
  4. 睡眠やアイパックでは根本的な影の段差は変わらない理由を模型で説明する
  5. 「疲れてないのに疲れ顔」と言われる人に教えてあげてと結ぶ
演出

スタッフの顔にペンライトを当て、ライトの角度（上から・正面から）を変えて影の消え方を検証する実験風の画角。

キャプションの冒頭

「しっかり寝たのにクマが消えない」と嘆いている人に教えてあげてください。 実は睡眠不足の青クマではなく、段差の影クマかもしれません。

根拠と、気をつける点
なぜ効くか

高共有手本「【目の下のたるみ】クマ治療した結果...」（共有率0.37%）の共感軸と、日常の会話で話題にしやすい「睡眠とクマの誤解」を結びつけてシェアを狙う。

気をつける点

医学的な断定表現を避け、「影によって暗く見えているケースが多い」と説明する。

4

目の下のぷっくり、正体は？💡

視聴時間狙い クイズ・問いかけ 目の下の膨らみやたるみが出始めて、クマなのか何なのか自己診断できずに悩んでいる30代〜40代
冒頭で言う

「皆さん、この目の下のぷっくり、正体わかりますか？」

送る相手の一言

「最近疲れて見える？」と気にするご家族に、この見分け方を教えてあげてください。

流れ
  1. 毛利先生がカメラにグッと近づき、自身の目の下を指差しながら冒頭の問いかけを行う
  2. 手元の目元模型やイラストを使い、膨らみの原因が「脂肪（黒クマ）」なのか「たるみ」なのか、構造の違いを動きをつけて解説
  3. 先生が実際にスタッフの目元を軽く押したり、上を向かせたりして、自宅の鏡の前ですぐにできる簡易セルフチェック法を実演
  4. 「実は、これをただの疲れだと思ってマッサージで押し戻そうとすると、逆効果になることがあります」とネガティブなリスクを提示して引きを作る
  5. 「あなたのぷっくりはどちらのタイプでしたか？コメント欄で教えてください」とエンゲージメントを促して締めくくる
演出

冒頭はカメラを先生の目元にズームインさせて映像的な引き（ビジュアルフック）を作る。中盤では目元の模型を実際に動かしながら、指で構造を示すことで視聴者の視線を釘付けにする。に1回はカットを切り替え、テンポよくテンションを維持する。

キャプションの冒頭

「最近疲れて見える？」と気にするご家族に、この見分け方を教えてあげてください。 目の下のぷっくりを自己流で触って悪化させる前に、まずはこのチェックを試してみてください。

根拠と、気をつける点
なぜ効くか

うちで当たった本「その白いポツポツ、”汗管腫”？（平均視聴23.）」「目の下のこのブツブツ、正体知ってますか？（平均視聴20.）」の『正体クイズ型』を応用。毛利先生を『動く役（模型を使った実演・診察検証）』にすることで、現在の平均視聴秒13.から当たりラインである超えを目指すため。

気をつける点

セルフチェックで病名や治療結果を断定せず、「〜の可能性が考えられます」「〜と感じる方が多いです」という表現を徹底する。「マッサージNG」の理由も、皮膚の構造上のリスクとして客観的に説明する。
